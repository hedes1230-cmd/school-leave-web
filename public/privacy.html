ความเป็นส่วนตัว

ข้อมูลและวัตถุประสงค์

ระบบใช้ชื่อ ระดับชั้นที่เลือก รหัสบัญชีหรืออีเมลตามวิธีเข้าสู่ระบบ บทบาท รหัสผู้ใช้ การเชื่อมต่อ ใบลา เหตุผล รูปแนบ และประวัติการพิจารณา เพื่อจัดการการลาและแสดงผลให้ผู้ที่เกี่ยวข้อง ข้อมูลการใช้งานอยู่ใน Firebase ส่วนบัญชีรหัสผู้ใช้ ค่าแฮชรหัสผ่าน ข้อมูลกู้บัญชี และบันทึกความปลอดภัยอยู่ใน Cloudflare D1 หน้าเว็บให้บริการผ่าน Cloudflare

บทบาทและการค้นหา

แต่ละบัญชีเลือกนักเรียนหรือครูได้หนึ่งบทบาทและเปลี่ยนเองไม่ได้ การเลือกครูไม่ใช่การรับรองจากสถานศึกษา ผู้ใช้ที่ผ่านเงื่อนไขยืนยันบัญชีและมีโปรไฟล์ค้นหาชื่อเต็มตรงกันได้ครั้งละไม่เกิน 10 รายการ หรือค้นด้วยรหัสเชื่อมต่อ ผลค้นหาแสดงชื่อ บทบาท รหัสบัญชีเมื่อมี และระดับชั้นที่นักเรียนเลือก โดยไม่แสดงอีเมลหรืออีเมลแบบย่อ โปรดตรวจสอบบุคคลจริงก่อนเชื่อมต่อ

ใครเข้าถึงข้อมูล

กฎฐานข้อมูลจำกัดการอ่านใบลาและรูปแนบให้ผู้ส่งและครูผู้รับที่ระบุ รวมถึงตรวจสิทธิ์เซสชัน ข้อมูลโปรไฟล์ส่วนตัวและอีเมลในฐานข้อมูลอ่านได้เฉพาะเจ้าของบัญชี ผู้ใช้คนอื่นอ่านได้เฉพาะข้อมูลสมุดรายชื่อที่ไม่มีอีเมล แม้เชื่อมต่อกันแล้ว ผู้ดูแลโครงการและบัญชีบริการที่ได้รับสิทธิ์อาจเข้าถึงข้อมูลผ่านระบบจัดการได้ จึงไม่ได้จำกัดการเข้าถึงเฉพาะสองบุคคลนี้ในทุกกรณี

รูปหลักฐานและไฟล์ส่งออก

รูปแนบเป็นตัวเลือก ควรปิดข้อมูลสุขภาพหรือข้อมูลส่วนบุคคลที่ไม่จำเป็นก่อนแนบ หน้าเว็บแปลงรูปที่รองรับเป็น JPEG และย่อขนาดก่อนบันทึกเป็นข้อมูลภาพใน Firebase Realtime Database การแปลงรูปไม่ใช่การรับรองว่าเนื้อหาปลอดภัยหรือไม่มีข้อมูลส่วนบุคคล ไฟล์ส่งออกประวัติอาจมีชื่อและเหตุผลลา โปรดดูแลไฟล์ที่ดาวน์โหลดไว้

รหัสผ่านและการกู้บัญชี

สมัครด้วยรหัสบัญชีได้โดยไม่ใช้อีเมล รหัสผ่านถูกส่งผ่าน HTTPS ไปประมวลผลที่ Cloudflare แล้วส่งเฉพาะค่า HMAC ที่คำนวณจากรหัสผ่านพร้อม salt ไปยัง Render เพื่อคำนวณ PBKDF2-SHA256 จำนวน 600,000 รอบ ไม่ส่งรหัสผ่านตรง ๆ ชื่อผู้ใช้ กุญแจ Firebase หรือ pepper ไป Render ระบบเก็บค่าแฮชสำหรับตรวจรหัสผ่านใน D1 และใช้ Firebase ออกเซสชัน รหัสกู้คืนแสดงเมื่อออกชุดรหัสและแต่ละรหัสใช้ได้ครั้งเดียว หากขั้นตอนเปิดบัญชีไม่สมบูรณ์ ระบบอาจออกชุดใหม่ให้ ต้องเก็บรหัสที่ได้รับล่าสุดไว้เป็นส่วนตัว

บันทึกและการป้องกันบอต

ระบบบัญชีเก็บเหตุการณ์ความปลอดภัย เวลา รหัสผู้ใช้ที่เกี่ยวข้อง และค่าแฮชของ IP เพื่อจำกัดคำขอและตรวจการใช้งานผิดปกติ ใช้ Cloudflare Turnstile สำหรับสมัคร เข้าสู่ระบบ และกู้บัญชี และใช้ Firebase App Check กับ Google reCAPTCHA Enterprise ในการเรียกใช้ที่เกี่ยวข้อง บริการเหล่านี้ประมวลผลข้อมูลทางเทคนิคของเบราว์เซอร์และคำขอ โค้ดบริการแฮชบน Render ไม่เขียนเนื้อหาคำขอหรือค่าแฮชลงไฟล์ แต่ผู้ให้บริการโครงสร้างพื้นฐานอาจเก็บบันทึกทางเทคนิคตามนโยบายของตน

เซสชันและอุปกรณ์ส่วนกลาง

ระบบตั้ง Firebase ให้เก็บสถานะเข้าสู่ระบบแบบเซสชันของแท็บ หน้าใช้งานที่เปิดอยู่ตรวจการไม่มีการโต้ตอบประมาณ 30 นาทีเพื่อออกจากระบบ การตรวจนี้ทำในเบราว์เซอร์ อาจช้าลงเมื่อแท็บหรืออุปกรณ์พัก และไม่ใช่การบังคับหมดอายุทันทีที่เซิร์ฟเวอร์ โปรดกดออกจากระบบเองเมื่อใช้อุปกรณ์ร่วมกัน การเข้าสู่ระบบ Google ยังอยู่ภายใต้การตั้งค่าบัญชี Google ของคุณ

ข้อมูลในอุปกรณ์

เบราว์เซอร์เก็บข้อมูลที่จำเป็นต่อเซสชันและการใช้งานแอป ระบบแจ้งเตือนมีคิวใน localStorage ประกอบด้วยชนิดเหตุการณ์ รหัสรายการ และเวลา โดยเลือกประมวลผลรายการอายุไม่เกิน 24 ชั่วโมง ข้อมูลที่ค้างอาจยังอยู่จนระบบทำงานหรือล้างข้อมูลเว็บไซต์ Service Worker แคชหน้าออฟไลน์สาธารณะ ไม่ได้ตั้งให้แคชใบลา รูปหลักฐาน หรือ API บัญชี การล้างข้อมูลเว็บไซต์อาจทำให้ต้องเข้าสู่ระบบและตั้งแจ้งเตือนใหม่

การแจ้งเตือน

เมื่อเปิดแจ้งเตือน ระบบเก็บรหัสผู้ใช้ ปลายทาง Push และกุญแจของการสมัครรับแจ้งเตือนใน Cloudflare สูงสุด 3 อุปกรณ์ต่อบัญชี โค้ดกำจัดอุปกรณ์ที่ไม่อัปเดตเกิน 90 วันเมื่อมีการประมวลผลเหตุการณ์แจ้งเตือน จึงไม่รับประกันการลบตรงวัน ข้อความที่ระบบส่งไม่ใส่ชื่อบุคคล เหตุผลลา หรือรูปหลักฐาน แต่บอกประเภทเหตุการณ์ เช่น มีใบลาใหม่ เปิด–ปิดได้จากสวิตช์ในเมนูตั้งค่าหรือการตั้งค่าเบราว์เซอร์ โดยมีผลกับอุปกรณ์นั้น การส่งอาศัยผู้ให้บริการ Push และอินเทอร์เน็ต

การเก็บ ลบ และสำรองข้อมูล

ครูและนักเรียนแก้ชื่อได้ที่เมนูตั้งค่า นักเรียนเลือกระดับชั้น ม.1–ม.6 หรือไม่ระบุได้ ชื่อที่บันทึกในใบลาเดิมอาจยังเป็นชื่อ ณ วันที่ส่ง ยกเลิกใบลาที่ยังรออนุมัติได้ โดยลบรายการและรูปแนบจากฐานข้อมูลหลักในคำสั่งเดียว ประวัติที่พิจารณาแล้วและประวัติการเปลี่ยนผลยังเก็บไว้ ระบบยังไม่มีกำหนดลบอัตโนมัติสำหรับข้อมูลบัญชี ใบลา และบันทึกทั้งหมด มีสำเนาสำรอง Firebase แบบเข้ารหัสที่ผู้ดูแลเคยจัดเก็บนอกฐานข้อมูลหลัก การลบจากระบบหลักไม่ลบสำเนาเดิมหรือไฟล์ส่งออกย้อนหลังโดยอัตโนมัติ และยังไม่มีกำหนดระยะเก็บสำเนาสำรองที่ประกาศไว้

สถิติการเข้าชม

ใช้ Cloudflare Web Analytics เพื่อดูจำนวนครั้งที่เข้าชม การเปิดหน้าเว็บ และประสิทธิภาพการโหลด โดยส่งข้อมูลหน้าเว็บและข้อมูลทางเทคนิคที่จำเป็นไปยัง Cloudflare ไม่ส่งชื่อ รหัสบัญชี เหตุผลลา หรือรูปหลักฐานเป็นข้อมูลสถิติของระบบ

ผู้ให้บริการภายนอก

เว็บใช้ Google/Firebase, Cloudflare และ Render ตามหน้าที่ข้างต้น รวมถึงโหลดฟอนต์และไฟล์ประกอบจากบริการภายนอก เช่น Google Fonts และ CDN ผู้ให้บริการได้รับข้อมูลทางเทคนิคที่จำเป็นต่อคำขอ เช่น IP และข้อมูลเบราว์เซอร์ การจัดเก็บและประมวลผลอาจเกิดนอกประเทศไทยตามบริการและการตั้งค่าของผู้ให้บริการ ดู นโยบาย Google, นโยบาย Cloudflare และ นโยบาย Render

การจัดการข้อมูลที่ยังไม่รองรับ

ขณะนี้เว็บยังไม่มีปุ่มให้แก้ไขหรือลบข้อมูลทุกประเภทด้วยตนเอง และไม่ได้ประกาศช่องทางรับคำขอด้านข้อมูลส่วนบุคคลโดยเฉพาะ หน้านี้จึงไม่รับรองว่าคำขอแก้ไขหรือลบข้อมูลจะดำเนินการได้ผ่านเว็บไซต์ โปรดพิจารณาข้อจำกัดนี้ก่อนส่งข้อมูล โดยเฉพาะข้อมูลอ่อนไหว

ผู้ช่วย AI

เมื่อส่งคำถาม ระบบส่งเฉพาะข้อความที่คุณพิมพ์และคู่มือใช้งานที่เลือกตามบทบาทครูหรือนักเรียนให้ Cloudflare Workers AI ประมวลผล ไม่ส่งชื่อ อีเมล รายละเอียดโปรไฟล์ ใบลา หรือหลักฐานให้อัตโนมัติ กรุณาอย่าพิมพ์รหัสผ่าน รหัสกู้คืน หรือข้อมูลส่วนตัวและสุขภาพ ระบบไม่บันทึกบทสนทนาลงฐานข้อมูลของเว็บ ข้อความบนหน้าจอหายเมื่อโหลดหน้าใหม่หรือออกจากระบบ มีตัวนับการใช้งานที่ผูกกับรหัสผู้ใช้เพื่อจำกัดโควตา และล้างรายการที่เก่ากว่า 2 วันเมื่อมีการเรียกบริการครั้งถัดไป คำตอบสร้างโดย AI และอาจไม่ถูกต้อง

สิทธิ์ผู้ดูแลในเว็บ

บัญชี Google ที่เจ้าของโครงการกำหนดเป็นผู้ดูแลสามารถดูรายชื่อผู้ใช้และใบลาทั้งระบบ แก้ชื่อและชั้นเรียน และพิจารณาใบลารออนุมัติผ่าน API ที่ตรวจสิทธิ์บนเซิร์ฟเวอร์ สิทธิ์นี้แยกจากบทบาทครูและไม่ให้ผู้ใช้สมัครเป็นผู้ดูแลเอง ระบบบันทึกรหัสผู้ดำเนินการ ประเภทการเปลี่ยนแปลง รหัสรายการ เวลา และสถานะการบันทึกเพื่อการตรวจสอบ บันทึกนี้ยังไม่มีการลบอัตโนมัติตามระยะเวลา หน้าผู้ดูแลไม่เปิดให้ดูรหัสผ่าน รหัสกู้คืน หรือกุญแจระบบ
